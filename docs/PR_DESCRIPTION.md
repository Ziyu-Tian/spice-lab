修复 rootless ngspice 安装后 `spinit` 仍引用系统 Code Model 绝对路径的问题，并新增真实 BJT 表观电阻实验。RC 成功只能证明该 RC 电路正常；本次另行检查六库的动态链接、模型注册及实际模拟/数字 Code Model 计算。

BJT 实验使用显式 generic NPN 模型，集电极为测量端口，基极经 10 kΩ 接独立偏置源。参考电阻为 3399、2641、1858 Ω，扫描 ±10/50/100 µA、零电流、0/25/50°C、六个固定偏置及三个单点校准后冻结的偏置。静态 V/I、DC 差分 dV/dI 和 AC 复阻抗分别保存。

名义 25°C、+50 µA 下可把 V/I 调到目标值，但 DC 差分电阻分别为 19942.815、4872.895、1329.341 Ω，误差 +486.726%、+84.509%、−28.453%。冻结偏置的 54 个非零条件中，静态 1% 判据只有三个校准点通过，动态 1% 判据全部失败。此拓扑与模型不能在所扫条件下稳定替代理想电阻。

验证：

- Code Model 18 项检查通过；六库加载，analog gain 和 ADC→数字反相器→DAC 实际求解通过。修复后 RC 回归通过，已有 RC 电路、测试与示例保持原样。
- 正式扫描 298 次 ngspice 执行、252 工作点、756 AC 结果、432 行误差比较；正式执行警告和失败均为零。
- 2462 个归档文件 SHA-256 核对通过，全部 CSV 的 OP/AC/差分值与原始输出一致。
- 一键流程重新执行，六类 CSV 与正式结果一致。另有 8 次实际衬底对照，确认省略衬底的三端电流和遗漏数值 gmin 支路。
- 开发期间未通过的检查和无效内部向量请求单独保留，不冒充正式成功结果。

CSV、PNG、技术报告、命令、版本、退出码及原始证据位于 `examples/bjt_resistance/` 和 `examples/code_model_validation/`。复现命令：`bash scripts/run_bjt_experiment.sh`，每次在 `results/` 下建立新的输出目录。

模型没有雪崩击穿、自热或厂商公差。±5 V 和 1% 均为实验判据，不是 HVAC 或 DS3930 规格；38 个超出窗口的 BJT 数学解保留并标记。结论限定于本模型和拓扑，不假设 DS3930 内部模型或控制器实际采样条件。
